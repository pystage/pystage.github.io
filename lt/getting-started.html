Pirmi žingsniai

Įdiek PyStage, paleisk pirmą programą ir sužinok, kaip Python kodas veikia kaip Scratch scenarijus.

Įdiegimas

pip install --pre pystage

Lietuviška API kol kas yra tik išankstinėje (angl. pre-release) versijoje, todėl reikia parametro --pre. Tai peržiūrinė versija: kol nėra oficialaus leidimo, kai kas gali keistis.

PyStage reikia Python 3.10 ar naujesnės versijos. pygame-ce įdiegiamas automatiškai. Jei esi įdiegęs klasikinį pygame, pirmiausia pašalink jį komanda pip uninstall pygame.

Tavo pirma programa

Išsaugok šį kodą faile, pavyzdžiui, pirma.py, ir paleisk jį su Python. Atsidarys langas, o veikėjas apeis kvadratą.

from pystage.lt import Scena, Veikėjas

scena = Scena()
zombis = scena.pridėk_veikėją()

def daryk(zombis: Veikėjas):
    for i in range(4):
        zombis.eik(10)
        zombis.pasisuk_kairėn_laipsnių(90)
        zombis.palauk_sek(1)

zombis.kai_spusteli_žalią_vėliavėlę(daryk)

scena.paleisk()

Naudok redaktoriaus automatinį užbaigimą, kad pamatytum, kokie metodai yra. Yra metodai visiems Scratch blokams, prijungti prie tavo scenos ir veikėjų objektų, įskaitant Pieštuko plėtinį, kintamuosius, sąrašus, klonus ir visus įvykius. Vieninteliai blokai, kurie nieko neveikia, yra tie, kuriems reikia mikrofono (garsumas).

Visas sąrašas pateiktas lietuviškame API žinyne; kitos kalbos turi savo.

Tavo kodas veikia kaip Scratch scenarijus

Kai kas veikia kitaip nei įprastose Python programose, nes tavo kodas veikia kaip Scratch scenarijus.

Ciklai atnaujina ekraną

Ekranas atnaujinamas po kiekvienos ciklo iteracijos ir po blokų, kurie užtrunka, pavyzdžiui, palauk_sek. Tau nereikia rūpintis žaidimo ciklu.

Funkcijos yra savo komandos

Funkcijos tame pačiame faile, kurias iškvieči iš savo kodo, veikia kaip Scratch savo komandos (blokai), todėl jose taip pat gali būti ciklų ir palauk_sek.

Vykdyti be ekrano atnaujinimo

Pažymėk funkciją @be_ekrano_atnaujinimo ir ji bus įvykdyta iš karto, kaip „Vykdyti be ekrano atnaujinimo“ Scratch programoje. Toliau pateiktame pavyzdyje kvadratas nupiešiamas iš karto.

from pystage.lt import Scena, Veikėjas, be_ekrano_atnaujinimo

scena = Scena()
zombis = scena.pridėk_veikėją()

def šuolis(zombis: Veikėjas, aukštis):
    for i in range(10):
        zombis.y_padidink(aukštis / 10)
    for i in range(10):
        zombis.y_padidink(-aukštis / 10)

@be_ekrano_atnaujinimo
def piešk_kvadratą(zombis: Veikėjas):
    # Kaip „Vykdyti be ekrano atnaujinimo“ Scratch programoje:
    # kvadratas atsiranda iš karto.
    zombis.pieštukas_pieš()
    for i in range(4):
        zombis.eik(50)
        zombis.pasisuk_kairėn_laipsnių(90)
    zombis.pieštukas_nebepieš()

def daryk(zombis: Veikėjas):
    piešk_kvadratą(zombis)
    while True:
        šuolis(zombis, 80)
        zombis.palauk_sek(1)

zombis.kai_spusteli_žalią_vėliavėlę(daryk)

scena.paleisk()

Klaidos rodomos

Jei tavo kode yra klaida, pranešimas rodomas lange ir terminale.

Kitos kalbos

Pavyzdžiuose naudojama lietuviška API: from pystage.lt import Scena, Veikėjas. Anglų (pystage.en) ir vokiečių (pystage.de) kalbomis naudojami Scratch blokų pavadinimai tomis kalbomis.

Galimos anglų, vokiečių ir lietuvių kalbos. Dokumentacijos puslapyje rasi kiekvienos kalbos žinyno nuorodą. Lietuvių kalba yra nauja. Susisiek, jei nori padėti prižiūrėti vertimą arba pridėti kitą kalbą.

Erste Schritte

Installiere PyStage, starte dein erstes Programm und lerne, wie sich Python-Code wie ein Scratch-Skript verhält.

Installieren

pip install pystage

PyStage braucht Python 3.10 oder neuer. pygame-ce wird automatisch mitinstalliert. Falls du das klassische pygame installiert hast, entferne es vorher mit pip uninstall pygame.

Dein erstes Programm

Speichere den Code in einer Datei, zum Beispiel erstes.py, und starte sie mit Python. Es öffnet sich ein Fenster, und die Figur läuft im Quadrat.

from pystage.de import Bühne, Figur

bühne = Bühne()
zombie = bühne.füge_eine_figur_hinzu()

def los(zombie: Figur):
    for i in range(4):
        zombie.gehe_schritte(10)
        zombie.drehe_dich_nach_links_um_grad(90)
        zombie.warte_sekunden(1)

zombie.wenn_programm_startet(los)

bühne.abspielen()

Mit der Autovervollständigung deines Editors siehst du, welche Methoden es gibt. Du findest Methoden für alle Scratch-Blöcke an deiner Bühne und deinen Figuren, auch für die Erweiterung Stift, für Variablen, Listen, Klone und alle Ereignisse. Nur die Blöcke, die ein Mikrofon brauchen (Lautstärke), tun nichts.

Die vollständige Liste steht in der Dokumentation.

Dein Code verhält sich wie ein Scratch-Skript

Manches funktioniert anders als in normalen Python-Programmen, weil sich dein Code wie ein Scratch-Skript verhält.

Schleifen aktualisieren den Bildschirm

Der Bildschirm wird nach jedem Durchlauf einer Schleife und nach Blöcken, die Zeit brauchen, aktualisiert, zum Beispiel nach warte_sekunden. Um eine Spielschleife musst du dich nicht kümmern.

Funktionen sind eigene Blöcke

Funktionen aus derselben Datei, die du in deinem Code aufrufst, verhalten sich wie eigene Blöcke in Scratch. Sie dürfen deshalb auch Schleifen und warte_sekunden enthalten.

Ohne Bildschirmaktualisierung ausführen

Markiere eine Funktion mit @ohne_bildschirmaktualisierung, dann läuft sie auf einmal ab, wie „Wiederhole ohne Bildschirmaktualisierung“ in Scratch. Im Beispiel unten ist das Quadrat sofort gezeichnet.

from pystage.de import Bühne, Figur, ohne_bildschirmaktualisierung

bühne = Bühne()
zombie = bühne.füge_eine_figur_hinzu()

def springe(zombie: Figur, höhe):
    for i in range(10):
        zombie.ändere_y_um(höhe / 10)
    for i in range(10):
        zombie.ändere_y_um(-höhe / 10)

@ohne_bildschirmaktualisierung
def zeichne_quadrat(zombie: Figur):
    # Wie "Wiederhole ohne Bildschirmaktualisierung" in Scratch:
    # Das Quadrat ist sofort da.
    zombie.schalte_stift_ein()
    for i in range(4):
        zombie.gehe_schritte(50)
        zombie.drehe_dich_nach_links_um_grad(90)
    zombie.schalte_stift_aus()

def los(zombie: Figur):
    zeichne_quadrat(zombie)
    while True:
        springe(zombie, 80)
        zombie.warte_sekunden(1)

zombie.wenn_programm_startet(los)

bühne.abspielen()

Fehler werden angezeigt

Wenn dein Code einen Fehler enthält, erscheint die Meldung im Fenster und im Terminal, auf Deutsch.

Andere Sprachen

Die Beispiele benutzen die deutsche API: from pystage.de import Bühne, Figur. Es gibt auch Englisch (pystage.en) und Litauisch (pystage.lt).

Englisch, Deutsch und Litauisch sind verfügbar. Auf der Doku-Seite findest du die Beschreibung der deutschen API. Hilf mit, wenn du eine Übersetzung pflegen oder eine neue Sprache hinzufügen möchtest, melde dich einfach.

Programmieren wie in Scratch, mit Python

PyStage verbindet Scratch und Python. Es ist eine Python-Bibliothek, die alle Scratch-Blöcke als Python-Methoden anbietet, und ein Umwandler, der deine Scratch-Projekte in Python-Code verwandelt. Grafik und Klang laufen auf PyGame.

1. Installieren

Ein Befehl, Python 3.10 oder neuer.

pip install pystage

Erste Schritte

2. Scratch-Projekt umwandeln

Lade ein Projekt oder eine .sb3-Datei hoch und bekomme ein Python-Projekt, das sofort läuft.

Scratch-Blöcke, als Python geschrieben

Zu jedem Scratch-Block gibt es eine passende Methode. Skripte, die mit einem Hut-Block beginnen, werden zu Funktionen, die du mit demselben Ereignis verbindest. PyStage aktualisiert den Bildschirm nach jedem Durchlauf einer Schleife und nach Blöcken wie warte_sekunden. Dein Code verhält sich deshalb wie ein Scratch-Skript, und du musst keine Spielschleife schreiben.

Ein vollständiges Beispiel

Dieses Programm legt eine Bühne und eine Figur auf der Bühne an. Die Funktionen sind Code-Blöcke. Mit den passenden Methoden verbindest du sie mit Ereignissen (das sind die Hut-Blöcke in Scratch).

from pystage.de import Bühne

bühne = Bühne()
bühne.füge_bühnenbild_hinzu("grid")
zombie = bühne.füge_eine_figur_hinzu()

def los(zombie):
    zombie.sage("Hallo pyStage!")
    for i in range(4):
        zombie.gehe_schritte(10)
        zombie.warte_sekunden(1)
        zombie.denke("Das ist toll!")
        zombie.drehe_dich_nach_links_um_grad(90)
        zombie.warte_sekunden(1)
        zombie.denke("")
    zombie.sage("Bewege mich mit WASD.")

zombie.wenn_programm_startet(los)

def rechts(zombie):
    zombie.ändere_x_um(10)

def links(zombie):
    zombie.ändere_x_um(-10)

def hoch(zombie):
    zombie.ändere_y_um(10)

def runter(zombie):
    zombie.ändere_y_um(-10)

zombie.wenn_taste_gedrückt_wird("d", rechts)
zombie.wenn_taste_gedrückt_wird("a", links)
zombie.wenn_taste_gedrückt_wird("w", hoch)
zombie.wenn_taste_gedrückt_wird("s", runter)

bühne.abspielen()

Warum PyStage?

  • Exportiere dein Scratch-Projekt als echten, ausführbaren Python-Code.
  • Hilf Programmieranfängern, Python „mit Scratch“ zu lernen.
  • Scratch-Blöcke in mehreren Sprachen, das ist ideal für Kinder. Im Moment gibt es Englisch, Deutsch und Litauisch.
Alpha-Version. Nicht alles funktioniert schon so, wie es soll. Wenn etwas kaputt geht, melde dich bitte oder eröffne ein Issue.

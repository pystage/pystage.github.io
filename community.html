Community and contributing

PyStage is an open-source project. Questions, ideas, bug reports and help are welcome.

Get in touch

  • Discord: join our Discord server to ask questions or just say hello.
  • Bugs and ideas: open an issue on GitHub. If a Scratch project does not convert or run as expected, tell us.
  • Translations: English, German and Lithuanian are available (see Documentation). Get in touch if you want to help maintain a translation.

Contribute

The code lives on GitHub. See the contributing guide in the repository for how to propose changes. This website has its own repository, pystage.github.io, and fixes to the text are welcome there too.

The package is on PyPI, and the documentation on Read the Docs.

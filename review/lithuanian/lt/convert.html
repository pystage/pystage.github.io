Konvertuok savo Scratch projektą

Paversk Scratch 3 projektą Python kodu, kuris veikia su PyStage.

Naudok konverterį internete

  1. Paskelbk savo Scratch projektą arba atsisiųsk jį kaip .sb3 failą.
  2. Eik į convert.pystage.org ir konvertuok projektą.
  3. Atsisiųsk gautą zip failą. Jame yra tavo naujas Python projektas, paruoštas paleisti.

Atidaryti konverterį

Konvertuok savo kompiuteryje

  1. Eksportuok savo Scratch projektą Scratch puslapyje. Gausi .sb3 failą.
  2. Naudok PyStage komandinės eilutės konverterį. Taip, jis nepatogus, ir mes dirbame, kad jį būtų lengviau naudoti.

Pagrindinė komanda:

python -m pystage.convert.sb3 <SB3 failas> -l lt -d <KATALOGAS>
ParinktisReikšmė
-lSugeneruotų Python „Scratch blokų“ kalba. Šiuo metu galimos en, de ir lt. Jei nenurodyta, naudojama nuo kalbos nepriklausoma pagrindinė API.
-dIšvesties katalogas, pagal nutylėjimą dabartinis katalogas.
-iSpausdinti tarpinį kodo vaizdą.
-sSpausdinti sb3 failo project.json.
-pSpausdinti Python kodą.
-vIšsami išvestis.
-vvDerinimo režimas.

Pirmiausia turi būti įdiegtas PyStage, žr. Pirmi žingsniai. Lietuviškam kodui (-l lt) reikia išankstinės versijos (pip install --pre pystage).

Kas konvertuojama

Konvertuojami tavo projekto scenarijai, savo komandos (blokai), kintamieji, sąrašai, monitoriai (scenoje rodomi kintamųjų ir sąrašų langeliai) ir komentarai.

Kas nepalaikoma

Blokai iš kitų plėtinių nei Pieštukas (pavyzdžiui, Muzika ar Skaityti tekstą) nepalaikomi. Python kode jie rodomi kaip tekstas, prasidedantis NOT SUPPORTED, todėl gali jo ieškoti ir tas dalis perrašyti rankomis.

Blokai, kuriems reikia mikrofono (garsumas), yra, bet nieko neveikia.

PyStage yra alfa versija, todėl konvertuotam projektui gali reikėti pataisymų. Jei rasi projektą, kuris konvertuojasi prastai, sukurk pranešimą (angl. issue).

Material

Lesson ideas, worksheets and background for teachers. This page is only available in English for now.

There is not much yet, and it will grow. What you can use today:

  • Projects : step-by-step projects for students. The first one is Make the zombie walk and talk .
  • Start : installing Python and PyStage and the first program, written for students.
  • Convert : students turn their own Scratch projects into Python and compare.
  • Documentation on Read the Docs: the technical reference (English).
  • Online converter : no installation needed on the teacher side.

Planned: lesson plans, worksheets and a comparison of Scratch concepts and Python concepts. If you have ideas or want to contribute material, tell us on Discord or in the issue tracker .

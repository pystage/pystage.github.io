Developers

PyStage is an open-source project. This page is for people who want to use the library in depth or help develop it. It is only available in English.

Code and documentation

  • README : overview, installation and usage.
  • CONTRIBUTING.md : how to propose changes (GitHub Flow, base branch development).
  • TRANSLATING.md : how translations work.
  • Read the Docs : the technical reference for the library, the converter and the localisation tools.
  • GitHub for the source and the issue tracker , PyPI for the package.
  • This website has its own repository, pystage.github.io .

Add a language

PyStage is English-canonical at its core; each language is a facade package (for example pystage.de) plus a table of dropdown values and messages. The steps are in TRANSLATING.md . For the website, a language needs i18n/<lang>.toml and the pages in content/<lang>/.

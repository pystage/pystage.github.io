Convert

Turn your Scratch project into Python code. Then you can see how your own project looks as a Python program.

Use the web converter

  1. Share your Scratch project or download it as an .sb3 file (“File”, then “Save to your computer”).
  2. Go to convert.pystage.org and convert your project.
  3. Download the zip file. It has your new Python project inside, ready to run.
  4. Unpack it and run the Python file. You need PyStage for this, see Start .

Open the converter

What is converted?

Your scripts, custom blocks, variables, lists, monitors and comments. Some things do not work yet. Read about it on the page For teachers .

PyStage is an alpha version, so a converted project may need some fixes. If your project does not convert well, please tell us.

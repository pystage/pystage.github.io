## Use the web converter

1. Share your Scratch project **or** download it as an .sb3 file ("File", then "Save to your computer").
2. Go to [convert.pystage.org](https://convert.pystage.org) and convert your project.
3. Download the zip file. It has your new Python project inside, ready to run.
4. Unpack it and run the Python file. You need PyStage for this, see [Start](/start/).

<p class="btns"><a class="btn" href="https://convert.pystage.org">Open the converter</a></p>

## What is converted?

Your scripts, custom blocks, variables, lists, monitors and comments. Some things do not work yet. Read about it on the page [For teachers](/teachers/#what-is-not-supported).

<div class="note">PyStage is an alpha version, so a converted project may need some fixes. If your project does not convert well, please <a href="https://github.com/pystage/pystage/issues">tell us</a>.</div>
